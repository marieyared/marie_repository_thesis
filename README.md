This repository contains the full implementation of the analytical workflow developed for the thesis “Characterization and Modelling of Residential Electricity Demand for Flexible Load Integration: The Case of Lebanon”. It includes all Python scripts used to preprocess and clean the raw microgrid data, extract transformer-level and household-level load profiles, and generate hourly, daily, and seasonal demand curves for the village of Bechaaleh. The code reconstructs the “duck-curve” behavior, computes average load profiles across transformers, visualizes variability in residential consumption, and produces monthly energy estimates used for validating the demand model against real measurements. In addition, the repository provides the full appliance-level demand modelling framework, enabling the simulation of yearly and seasonal load profiles across Lebanese climate zones for 12 demographic and climatic scenarios. Together, these scripts ensure full transparency and reproducibility of the modelling and validation steps presented in the thesis.
